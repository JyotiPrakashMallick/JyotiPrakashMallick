Systems are transitioning from single-threaded demos to enterprise-scale AI platforms where
reliability, high throughput, and fault tolerance are non-negotiable. That shift requires
engineers who obsess over performance engineering, distributed orchestration, bottlenecks,
and observability as much as model capability. That's the work I do.

<img align="right" src="assets/loadtest.svg?v=202610201521" width="240" alt="Load test — throughput ramps while p99 latency holds under the SLA" />

### What that looks like in numbers

- **Sub-100ms P99 latency SLAs** across distributed AI microservices handling millions of daily records and real-time transaction streams.
- **Automated enterprise load testing harnesses** with custom JMeter telemetry listeners streaming real-time metrics to Azure Cosmos DB & SQL Server.
- **2,000+ reputation & 80+ badges on Stack Overflow** contributing across cloud scalability, distributed architecture, and CI/CD pipelines.
